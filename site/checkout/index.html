Add Nullar Checkout to your site

One script. One element. No wallet, no card, no account, no fees.

<script type="module" src="https://nullar.org/checkout/nullar-pay.js"></script>

<nullar-pay item="Coffee" merchant="Your Shop"></nullar-pay>

Or install from npm

For React, Vue, Svelte or any bundler. Package: @nullar/checkout. Dependencies: 0.

npm i @nullar/checkout
import '@nullar/checkout';

// anywhere in your markup:
<nullar-pay item="Coffee" merchant="Your Shop"></nullar-pay>
import { getBalance, mine } from '@nullar/checkout/core';

getBalance(); // 0
mine();       // { reward: 0, completedBeforeStart: true }

Options

itemWhat is being bought. Up to 48 characters.
merchantOptional. Up to 48 characters.
labelOptional button text. ¤0 is always shown.
amountNot supported. The amount is ¤0.
event nullar:paid{ amount: 0, receiptId, stateChanged: false }
--nullar-pay-bg / -fgCSS variables for button colors. Default: black on white.

Nullar Checkout is part of a conceptual art project. It is not a payment processor and does not accept, hold or transfer money or crypto-assets. A Nullar receipt is not proof of payment for any amount other than ¤0.
